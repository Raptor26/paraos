# Общие сведения

`ROSAL` является слоем абстракции операционной системы.
Преследуемая цель заключается в создании обобщенного `API`, поддерживающего несколько операционных систем (ОС), включая операционные системы реального времени (ОСРВ) (такие, как `freeRTOS`) и ОС общего назначения (`Windows`, `Linux`).

## Постановка проблемы

Разработка ПО встраиваемых систем не имеет существенных отличий от разработки системного ПО. К общим чертам можно отнести использование:

- Системы контроля версий исходного кода;
- Паттернов проектирования;
- Операционных систем.

Если первые два пункта относятся к организационным моментам, то операционные системы имеют различный `API` относительно друг друга. Задача `ROSAL` заключается в унификации `API` различных ОС, т.е. необходимо предоставить пользователю единый `API`, скрывающий детали конкретны ОС.

Для микропроцессорных систем, отличающихся малыми объемами памяти, используются операционных системы реального времени, такие как `freeRTOS`, `ChibiOS`. Для решения задач разработки и отладки ПО можно написать обобщенную программную обертку над `API` операционных систем таким образом, что написанный программистом код не будет знать об используемой операционной системе. Это отрывает возможности *нативного* запуска кода, написанного для микропроцессорных систем, в среде операционных систем общего назначения.

При запуске порта freeRTOS в среде Windows наблюдается снижение производительности за счет эмуляции поведения ОС реального времени, а также невозможности гарантировать корректное поведение нескольких одновременно запущенных экземпляров программ (что, по всей видимости, связанно с особенностями порта freeRTOS для Windows).

Слой абстракции операционной системы (operation system abstract layer) использует нативный API ОС, что исключает потери производительности, связанные с эмуляцией окружения, а также обеспечивает полную независимость
