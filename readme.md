# Общие сведения

`PARAOS` является слоем абстракции операционной системы.
Преследуемая цель заключается в создании обобщенного `API`, поддерживающего несколько операционных систем (ОС), включая операционные системы реального времени (ОСРВ) (такие, как `freeRTOS`) и ОС общего назначения (`Windows`, `Linux`). В отличие от других кроссплатформенных инструментов, `PARAOS` преследует цель предоставить API максимально удобный для разработки встраиваемых систем. Поддержка операционных систем общего назначения рассматривается как необходимость для проведения различного вида тестов на рабочей машине разработчика с нативным выполнением кода (и примитивов операционных систем), без лишних слоев абстракций, что неизбежно возникает при использовании портированной версии ОСРВ (например, при запуске freeRTOS под windows/linux). Также, при поддержке нескольких ОРСВ, переключение с одной на другую достигается за счет изменения конфигурации системы сборки *без необходимости внесения изменений в исходный код*.

## Стадия проекта

На текущий момент проект находится в **alpha** стадии.

## Поддерживаемые операционные системы

На текущий момент поддерживаются операционные системы:

- Windows
- Linux
- FreeRTOS

## Набор API

Каждый порт предоставляет следующий набор API:

- Потоки (paraos_thread.hpp)
- Семафоры (paraos_semaphore.hpp)
- Мьютексы (paraos_mutex.hpp)
- FIFO очередь в виде контейнера (paraos_queue.hpp)
- FIFO очередь в виде контейнера, которая может блокировать вызывающий поток при записи/чтении данных из очереди (paraos_queue_blocking.hpp)
- Буфер сообщений (paraos_message_buffer.hpp)
- Рабочие очереди (paraos_work_queue.hpp)
- Последовательность (paraos_thread_sequence.hpp)

## Как собрать проект

Для сборки проекта лучше всего воспользоваться cmake presets. Для получения списка доступных предустановок воспользуйтесь командой `cmake --list-presets`.

Вы увидите что-то вроде этого:
``` bash
Available configure presets:

  "pc_debug_clang"             - PC Debug Clang
  "pc_debug_clang_docker"      - Docker with clang and without sudo
  "pc_debug_clang_trace"       - PC Debug Clang with trace
  "pc_release_clang"           - PC Release Clang with trace
  "freertos_debug_clang"       - freeRTOS Debug Clang
  "freertos_release_clang"     - freeRTOS Release Clang
  "freertos_debug_clang_trace" - freeRTOS Debug Clang with trace
```

Вам необходимо сконфигурировать и собрать проект, используя одну из предустановок. Команда конфигурации имеет следующий синтаксис `cmake --preset <name-of-preset>`

Например:

``` bash
cmake --preset pc_debug_clang
```

Аналогично вы можете получить список предустановок сборки `cmake --build --list-presets`:
```bash
Available build presets:

  "build_pc_debug_clang"

```

Выполним сборку:

```bash
cmake --build --preset build_pc_debug_clang
```

Запуск тестов (опционально)

Запросите список доступных предустановок тестов командой `ctest --list-presets`

Ответом будет что-то вроде:

```bash
Available test presets:

  "test_pc_debug_clang"
```

Тогда, для запуска тестового набора используйте:

```bash
ctest --preset test_pc_debug_clang
```

## Запуск скрипта для тестирования проекта

Перед запуском скрипта, возможно, будет необходимо установить дополнительные зависимости для его работы. Для этого необходимо ввести следующую команду в терминале:

```
python install_builder_dependencies.py
```

Запуск скрипта для тестирования осуществляется с помощью одной из следующих команд:

```
python builder.py
```

```
python -m builder
```
