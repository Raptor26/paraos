# Общие сведения

`PARAOS` является слоем абстракции операционной системы.
Преследуемая цель заключается в создании обобщенного `API`, поддерживающего несколько операционных систем (ОС), включая операционные системы реального времени (ОСРВ) (такие, как `freeRTOS`) и ОС общего назначения (`Windows`, `Linux`). В отличие от других кроссплатформенных инструментов, `PARAOS` преследует цель предоставить API максимально удобный для разработки встраиваемых систем. Поддержка операционных систем общего назначения рассматривается как необходимость для проведения различного вида тестов на рабочей машине разработчика с нативным выполнением кода (и примитивов операционных систем), без лишних слоев абстракций, что неизбежно возникает при использовании портированной версии ОСРВ (например, при запуске freeRTOS под windows/linux). Также, при поддержке нескольких ОРСВ, переключение с одной на другую достигается за счет изменения конфигурации системы сборки *без необходимости внесения изменений в исходный код*.

## Стадия проекта

На текущий момент проект находится в **alpha** стадии.

## Поддерживаемые операционные системы

На текущий момент поддерживаются операционные системы:

- Windows
- Linux
- FreeRTOS

## Набор API

Каждый порт предоставляет следующий набор API:

- Потоки (paraos_thread.hpp)
- Семафоры (paraos_semaphore.hpp)
- Мьютексы (paraos_mutex.hpp)
- FIFO очередь в виде контейнера (paraos_queue.hpp)
- FIFO очередь в виде контейнера, которая может блокировать вызывающий поток при записи/чтении данных из очереди (paraos_queue_blocking.hpp)
- Буфер сообщений (paraos_message_buffer.hpp)
- Рабочие очереди (paraos_work_queue.hpp)
- Последовательность (paraos_thread_sequence.hpp)
