# Plan 30-01: Runtime verification on macOS

## Objective

Run the full CTest suites for the available PC and FreeRTOS presets on macOS
with a 20-second timeout, focusing on the migrated `test_thread_only_*`
standalone tests and confirming no regressions in the broader test suite.

## Must-Haves

- [ ] MH-01: `pc_debug_clang` — all tests pass with `--timeout 20`.
- [ ] MH-02: `pc_debug_gcc` — all tests pass with `--timeout 20`.
- [ ] MH-03: `freertos_debug_clang` — all tests pass with `--timeout 20`.
- [ ] MH-04: `freertos_debug_gcc` — all tests pass with `--timeout 20`.
- [ ] MH-05: The four `test_thread_only_*` tests are included in the runs and
  pass.
- [ ] MH-06: No platform-specific code paths outside `port_tests/` were
  modified; cross-platform compatibility is preserved.

## Tasks

### Task 1: PC runtime verification

**details:**
1. Configure and build `pc_debug_clang`.
2. Run `ctest --test-dir build/pc_debug_clang/ --timeout 20 --output-on-failure`.
3. Configure and build `pc_debug_gcc`.
4. Run `ctest --test-dir build/pc_debug_gcc/ --timeout 20 --output-on-failure`.

### Task 2: FreeRTOS runtime verification

**details:**
1. Configure and build `freertos_debug_clang`.
2. Run `ctest --test-dir build/freertos_debug_clang/ --timeout 20
   --output-on-failure`.
3. Configure and build `freertos_debug_gcc`.
4. Run `ctest --test-dir build/freertos_debug_gcc/ --timeout 20
   --output-on-failure`.

### Task 3: Cross-platform regression check

**details:**
1. Review `git diff --stat` to confirm changes are limited to
   `port_tests/test_thread_only_*.cpp` and `port_tests/CMakeLists.txt`.
2. Confirm no changes in `port_win/`, `port_unix/` (beyond what prior phases
   introduced), `port_freertos/`, or core headers.

## Verification

- All four presets pass CTest with `--timeout 20`.
- `git diff --stat` shows only the expected files changed.

## Risks

- FreeRTOS POSIX simulator on macOS can be slow; some FreeRTOS tests may
  approach the 20-second timeout. If a timeout occurs, investigate whether it
  is caused by the migrated tests or by pre-existing simulator behavior.
