# Plan 29-01: Update `port_tests/CMakeLists.txt` for migrated tests

## Objective

Bring `port_tests/CMakeLists.txt` in line with the migrated `test_thread_only_*`
standalone tests: ensure C++20, clang-tidy coverage, and a 20-second CTest
timeout for each target.

## Must-Haves

- [ ] MH-01: All four `test_thread_only_*` targets use
  `target_compile_features(... PRIVATE cxx_std_20 c_std_11)`.
- [ ] MH-02: All four `test_thread_only_*` targets are registered with
  `CXX_CLANG_TIDY` inside the existing `if(CLANG_TIDY_ENABLE)` block.
- [ ] MH-03: Each of the four `add_test(...)` calls includes `TIMEOUT 20`.
- [ ] MH-04: `pc_debug_clang`, `pc_debug_gcc_clang_tidy`, `freertos_debug_clang`,
  and `freertos_debug_gcc` presets configure and build without new warnings.

## Tasks

### Task 1: Verify/ensure C++20 compile features

**read_first:** `port_tests/CMakeLists.txt`

**details:**
1. Confirm that the four `target_compile_features` lines for
   `test_thread_only_static`, `test_thread_only_global`,
   `test_thread_only_stack`, and `test_thread_only_stack_with_multiple_threads`
   all specify `cxx_std_20`. If any still say `cxx_std_17`, update them.

### Task 2: Verify clang-tidy registration

**read_first:** `port_tests/CMakeLists.txt`

**details:**
1. Confirm that inside `if(CLANG_TIDY_ENABLE)` there are
   `set_target_properties(test_thread_only_* PROPERTIES CXX_CLANG_TIDY ...)`
   for all four targets.
2. No changes needed if already present.

### Task 3: Add CTest timeouts

**read_first:** `port_tests/CMakeLists.txt`

**details:**
1. Add `TIMEOUT 20` to each of the four `add_test` calls for
   `test_thread_only_static`, `test_thread_only_global`,
   `test_thread_only_stack`, and `test_thread_only_stack_with_multiple_threads`.

### Task 4: Build verification

**details:**
1. Configure and build `pc_debug_clang`.
2. Configure and build `pc_debug_gcc_clang_tidy` to confirm clang-tidy runs
   cleanly on the four migrated files.
3. Configure and build `freertos_debug_clang` and `freertos_debug_gcc` to
   confirm FreeRTOS paths still compile.

## Verification

- `pc_debug_gcc_clang_tidy` builds the four targets without new clang-tidy
  diagnostics.
- `ctest --test-dir build/pc_debug_clang/ -R test_thread_only_ --timeout 20`
  passes all four tests within 20 seconds.

## Risks

- The `pc_debug_gcc_clang_tidy` preset treats clang-tidy warnings as errors;
  any new diagnostic in the four files will fail the build. Already verified in
  Phase 28 that no new diagnostics appear.
