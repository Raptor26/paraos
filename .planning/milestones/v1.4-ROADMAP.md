# Milestone v1.4: std::semaphore-style Semaphore API

**Status:** ✅ SHIPPED 2026-06-22
**Phases:** 16-18
**Total Plans:** 3

## Overview

Добавлен кроссплатформенный API `paraos::counting_semaphore<LeastMaxValue>` и `paraos::binary_semaphore` в стиле `std::counting_semaphore` рядом со старым `paraos::SemaphoreCounting` / `paraos::SemaphoreBinary`. PC, Unix и Windows используют `std::counting_semaphore`; FreeRTOS реализован поверх FreeRTOS counting semaphore API.

## Milestone Summary

**Key Decisions:**

- `paraos::counting_semaphore` и `paraos::binary_semaphore` добавлены рядом с legacy `paraos::SemaphoreCounting` / `paraos::SemaphoreBinary`.
- PC/Unix/Windows используют `std::counting_semaphore` через `port_pc/paraos_semaphore_std.hpp`.
- FreeRTOS использует `xSemaphoreCreateCounting` / `xSemaphoreTake` / `xSemaphoreGive` с `std::chrono` таймаутами.
- Header name `paraos_semaphore_std.hpp` avoids include-guard collision with legacy `PARAOS_SEMAPHORE_HPP`.

**Issues Resolved:**

- Добавлена семафорная абстракция в стиле C++20 `std::counting_semaphore` для всех поддерживаемых платформ.
- Обеспечена совместимость с `std::chrono` таймаутами на FreeRTOS.

**Issues Deferred:**

- Полная замена legacy `paraos::SemaphoreCounting` / `paraos::SemaphoreBinary` — отдельная веха.
- `std::latch` или `std::barrier` — будущие вехи.
- Runtime-проверка на физических FreeRTOS-таргетах или Windows-хосте — нет доступного хоста/таргета.

**Technical Debt Incurred:**

- Отсутствуют отдельные phase-level `VERIFICATION.md` файлы для v1.4; верификация выполнена через аудит вехи (`v1.4-MILESTONE-AUDIT.md`).
