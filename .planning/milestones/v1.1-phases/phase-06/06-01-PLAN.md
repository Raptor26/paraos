# Phase 6 Plan: Fix Core, Headers & port_unix

**Phase:** 6 — Fix Core, Headers & port_unix
**Goal:** clang-tidy warnings in public core headers and `port_unix/` sources are fixed or documented as false positives.
**Depends on:** Phase 5
**Requirements:** CORE-01, CORE-02, PORT-01, PORT-02, PORT-03
**Mode:** Standard
**Context:** `.planning/phases/phase-06/06-CONTEXT.md`
**Research:** `.planning/phases/phase-05/WARNINGS.md`

## Success Criteria

1. No clang-tidy warnings remain in `paraos_*.hpp` / `paraos_*.h` files, or each remaining warning has an inline suppression with rationale.
2. No clang-tidy warnings remain in `port_unix/` sources, or each remaining warning has an inline suppression with rationale.
3. Public header signatures are unchanged.
4. Linux-specific code paths under `__linux__` are semantically unchanged.
5. The existing `.clang-tidy` check set is preserved.

## Plan Overview

Phase 5 produced a complete warning inventory. Phase 6 addresses all warnings that fall in the library/header scope:

- `readability-use-concise-preprocessor-directives` in `paraos_config.hpp`, `paraos_exceptions.hpp`, `paraos_thread_common.hpp`, `containers/paraos_queue_blocking.hpp`, and test-only headers' `#if defined(PARAOS_LIKE_FREERTOS)` guards that are pulled in via shared headers (the guards inside `containers/tests/*.cpp` are Phase 7, but the shared header `containers/paraos_queue_blocking.hpp:65` is Phase 6).
- `misc-multiple-inheritance` false positives in `paraos_exceptions.hpp` and `extra/paraos_thread_cooperative_scheduling.hpp`.
- `readability-redundant-parentheses` in `extra/paraos_thread_cooperative_scheduling.hpp`.

`port_unix/` contains only header files in this repository; any warnings in those headers are covered by the same header-fix tasks above. `port_unix/tests/test_paraos_utils.cpp` is a test file and belongs to Phase 7.

## Task 1 — Fix `readability-use-concise-preprocessor-directives` in core headers

**Scope:** `paraos_config.hpp`, `paraos_exceptions.hpp`, `paraos_thread_common.hpp`

**Details:**

1. Read each header file.
2. Replace every `#if defined(X)` with `#ifdef X` where the condition is a simple single-macro test.
3. Replace every `#if !defined(X)` with `#ifndef X` where the condition is a simple single-macro negated test.
4. Leave compound conditions (e.g., `#if defined(X) && defined(Y)`) unchanged.

**Files and lines from WARNINGS.md:**

- `paraos_config.hpp:17` — `#if defined(__clang__)` → `#ifdef __clang__`
- `paraos_config.hpp:33` — `#if defined(_MSC_VER)` → `#ifdef _MSC_VER`
- `paraos_exceptions.hpp:60` — `#if defined(PARAOS_VERBOSE_ERRORS)` → `#ifdef PARAOS_VERBOSE_ERRORS`
- `paraos_thread_common.hpp:37` — `#if defined(PARAOS_LIKE_WINAPI)` → `#ifdef PARAOS_LIKE_WINAPI`
- `paraos_thread_common.hpp:46` — `#if defined(PARAOS_LIKE_WINAPI)` → `#ifdef PARAOS_LIKE_WINAPI`

**Acceptance Criteria:**

- [ ] `grep -n "#if defined(" paraos_config.hpp paraos_exceptions.hpp paraos_thread_common.hpp` shows only compound conditions, not the five single-macro lines above.
- [ ] `grep -n "#ifdef __clang__" paraos_config.hpp` returns line 17.
- [ ] `grep -n "#ifdef _MSC_VER" paraos_config.hpp` returns line 33.
- [ ] `grep -n "#ifdef PARAOS_VERBOSE_ERRORS" paraos_exceptions.hpp` returns line 60.
- [ ] `grep -n "#ifdef PARAOS_LIKE_WINAPI" paraos_thread_common.hpp` returns lines 37 and 46.

**Scope:** `paraos_exceptions.hpp`

**Details:**

1. Read `paraos_exceptions.hpp`.
2. Locate `class exception : public std::exception, public etl::exception` (line 74).
3. Add a `// NOLINTBEGIN(misc-multiple-inheritance)` comment immediately before the class definition and a matching `// NOLINTEND(misc-multiple-inheritance)` after the closing brace of the class, **OR** add `// NOLINT(misc-multiple-inheritance)` on the same line as the class declaration.

**Acceptance Criteria:**
