# Phase 7 Plan: Fix Tests, Examples & Document Suppressions

**Phase:** 7 — Fix Tests, Examples & Document Suppressions
**Goal:** clang-tidy warnings in tests, examples, and other ancillary files are fixed or documented as false positives.
**Depends on:** Phase 6
**Requirements:** TEST-01, TEST-02, SUPP-01, SUPP-02
**Mode:** Standard
**Context:** `.planning/phases/phase-07/07-CONTEXT.md`
**Research:** `.planning/phases/phase-05/WARNINGS.md`, `.planning/phases/phase-06/pc_tidy_after_phase6.log`

## Success Criteria

1. No clang-tidy warnings remain in `port_tests/`, `containers/tests/`, `extra/tests/`, `port_unix/tests/`, or executable examples, or each remaining warning has an inline suppression with rationale.
2. Test logic and assertions are preserved; only style/static-analysis issues are changed.
3. Every `.clang-tidy` or inline suppression has a documented rationale.
4. The existing `.clang-tidy` check set is preserved.

## Plan Overview

Phase 6 removed all library/header-scoped warnings. This plan fixes the remaining 47 unique warnings in test/example `.cpp` files:

- `misc-use-internal-linkage` — move file-local structs/classes into anonymous namespaces.
- `llvm-prefer-static-over-anonymous-namespace` — add `static` to file-local helper functions already in anonymous namespaces.
- `misc-override-with-different-visibility` — change `SetUp()` visibility in `test_runtime_profiler.cpp` from `public` to `protected`.
- `llvm-use-ranges` — suppress inline; project targets C++17 and `std::ranges` is unavailable.
- `readability-redundant-parentheses` — remove redundant parentheses.
- `readability-use-concise-preprocessor-directives` — replace `#if defined(X)` with `#ifdef X` in `.cpp` files.

A `SUPPRESSIONS.md` file will capture every suppression rationale.
