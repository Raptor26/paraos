# Plan 24-02: Verify FreeRTOS scheduler API builds

## Objective

Confirm that the new `paraos::jthread` scheduler methods compile cleanly
under both FreeRTOS Clang and FreeRTOS GCC presets on the build host.

## Must-Haves

- [ ] MH-01: `freertos_debug_clang` preset configures successfully.
- [ ] MH-02: `freertos_debug_clang` builds the `paraos` target without errors.
- [ ] MH-03: `freertos_debug_gcc` preset configures successfully.
- [ ] MH-04: `freertos_debug_gcc` builds the `paraos` target without errors.
- [ ] MH-05: No new compiler warnings are introduced by the scheduler methods.

## Tasks

### Task 1: Build with FreeRTOS Clang

**details:**
1. Configure the preset:
   ```bash
   cmake --preset freertos_debug_clang
   ```
2. Build the library:
   ```bash
   cmake --build build/freertos_debug_clang/ --target paraos -j4
   ```

**acceptance_criteria:**
- Configuration succeeds.
- Build completes with exit code 0.
- No errors related to `paraos_jthread.hpp` scheduler methods.

### Task 2: Build with FreeRTOS GCC

**details:**
1. Configure the preset:
   ```bash
   cmake --preset freertos_debug_gcc
   ```
2. Build the library:
   ```bash
   cmake --build build/freertos_debug_gcc/ --target paraos -j4
   ```

**acceptance_criteria:**
- Configuration succeeds.
- Build completes with exit code 0.
- No errors related to `paraos_jthread.hpp` scheduler methods.

### Task 3: Capture build log

**details:**
1. Save the combined configure/build output to:
   `.planning/phases/24-freertos-scheduler-api/24-02-build.log`

**acceptance_criteria:**
- Log file exists and shows both presets built successfully.

## Verification

- Both FreeRTOS presets build without errors.
- Build log is committed as evidence.

## Risks

- macOS host cannot run FreeRTOS runtime tests; verification is build-only.
- FreeRTOS POSIX simulator may produce platform-specific warnings that are unrelated to this phase.
