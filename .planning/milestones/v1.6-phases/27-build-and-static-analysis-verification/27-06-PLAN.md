# Plan 27-06: Verify FreeRTOS multithread tests compile and do not hang

## Objective

Confirm that the six key multithread test targets compile under both FreeRTOS
presets. Runtime execution is build-only on the macOS POSIX simulator host.

## Must-Haves

- [ ] MH-01: `test_jthread_basic` compiles under `freertos_debug_clang` and `freertos_debug_gcc`.
- [ ] MH-02: Each updated container multithread test compiles under both FreeRTOS presets.

## Tasks

### Task 1: Build key FreeRTOS test targets

```bash
for target in test_jthread_basic test_queue_blocking_mpsc test_queue_blocking_spmc test_queue_blocking_mpmc test_multi_ringbuff_mpmc test_message_multithread_many_producer_many_consumers; do
  cmake --build build/freertos_debug_clang/ --target "$target" -j4
  cmake --build build/freertos_debug_gcc/ --target "$target" -j4
done
```

### Task 2: Capture log

Save output to `.planning/phases/27-build-and-static-analysis-verification/27-06-freertos.log`.

## Verification

- All six test targets compile in both FreeRTOS presets.
