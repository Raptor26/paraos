# Plan 27-05: Build freertos_debug_clang and freertos_debug_gcc

## Objective

Configure and build both FreeRTOS presets from a clean state.

## Must-Haves

- [ ] MH-01: `freertos_debug_clang` configures successfully.
- [ ] MH-02: `freertos_debug_clang` builds.
- [ ] MH-03: `freertos_debug_gcc` configures successfully.
- [ ] MH-04: `freertos_debug_gcc` builds.

## Tasks

### Task 1: Clean and build freertos_debug_clang

```bash
rm -rf build/freertos_debug_clang
cmake --preset freertos_debug_clang
cmake --build build/freertos_debug_clang/ -j4
```

### Task 2: Clean and build freertos_debug_gcc

```bash
rm -rf build/freertos_debug_gcc
cmake --preset freertos_debug_gcc
cmake --build build/freertos_debug_gcc/ -j4
```

## Verification

- Both presets build without errors.

## Risks

- macOS POSIX simulator may emit platform-specific warnings; these are not regressions if unrelated to milestone files.
