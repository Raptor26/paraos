# Plan 27-01: Build pc_debug_clang and pc_debug_gcc

## Objective

Configure and build the two primary PC Debug presets from a clean state.

## Must-Haves

- [ ] MH-01: `pc_debug_clang` configures successfully.
- [ ] MH-02: `pc_debug_clang` builds the `paraos` target and all tests.
- [ ] MH-03: `pc_debug_gcc` configures successfully.
- [ ] MH-04: `pc_debug_gcc` builds the `paraos` target and all tests.

## Tasks

### Task 1: Clean and configure pc_debug_clang

```bash
rm -rf build/pc_debug_clang
cmake --preset pc_debug_clang
```

### Task 2: Build pc_debug_clang

```bash
cmake --build build/pc_debug_clang/ -j4
```

### Task 3: Clean and configure pc_debug_gcc

```bash
rm -rf build/pc_debug_gcc
cmake --preset pc_debug_gcc
```

### Task 4: Build pc_debug_gcc

```bash
cmake --build build/pc_debug_gcc/ -j4
```

## Verification

- Both presets build without errors.

## Risks

- macOS host lacks POSIX timers for `port_unix`; use Linux or expect build failures if running natively on macOS.
