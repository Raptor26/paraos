# Plan 27-04: Build pc_debug_gcc_clang_tidy and check for new warnings

milestone's code changes.

## Must-Haves

- [ ] MH-01: `pc_debug_gcc_clang_tidy` configures successfully.
- [ ] MH-02: `pc_debug_gcc_clang_tidy` builds.
- [ ] MH-03: Build log captured.

## Tasks

```bash

cmake --build build/pc_debug_gcc_clang_tidy/ -j4 -- -k 0 2>&1 | tee .planning/phases/27-build-and-static-analysis-verification/27-04-tidy.log
```
