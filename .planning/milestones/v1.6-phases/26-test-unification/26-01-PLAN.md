# Plan 26-01: Update PC end_scheduler and rewrite test_jthread_basic

## Objective

Make it possible for a `paraos::jthread` worker thread to call
`end_scheduler()` without self-deadlock, then rewrite
`port_tests/test_jthread_basic.cpp` as the reference unified test.

## Must-Haves

- [ ] MH-01: `port_pc/paraos_jthread.hpp::end_scheduler()` skips the calling thread during join.
- [ ] MH-02: `test_jthread_basic.cpp` has no `std::_Exit()` and no `#ifdef PARAOS_LIKE_FREERTOS` branches.
- [ ] MH-03: `test_jthread_basic.cpp` calls `paraos::jthread::start_scheduler()`.
- [ ] MH-04: `test_jthread_basic.cpp` uses a stopper thread that calls `paraos::jthread::end_scheduler()`.
- [ ] MH-05: `test_jthread_basic.cpp` uses `paraos::sleep_for(std::chrono::milliseconds{...})`.
- [ ] MH-06: `test_jthread_basic.cpp` passes on PC.

## Tasks

### Task 1: Skip self-join in PC end_scheduler

**read_first:**
- `port_pc/paraos_jthread.hpp`

**details:**
1. Capture `std::this_thread::get_id()` at the start of `end_scheduler()`.
2. In the request-stop and join loops, skip any context whose thread id matches the caller.

### Task 2: Rewrite test_jthread_basic.cpp

**read_first:**
- `port_tests/test_jthread_basic.cpp`
- `port_tests/test_jthread_basic.cpp` reference pattern from Phase 26 context

**details:**
1. Remove `paraos::Thread` include and `std::_Exit` branch.
2. Add condition-variable helpers to signal scheduler shutdown.
3. Create worker threads, a stopper thread, call `start_scheduler()`, then wait for shutdown signal.
4. Verify counter equals expected value and return 0/EXIT_FAILURE.

## Verification

- `pc_debug_clang` builds `test_jthread_basic` and the executable prints `OK`.

## Risks

- If main calls `join()` while `end_scheduler()` also joins the same thread, a race causes `thread::join failed: Invalid argument`. The chosen pattern avoids explicit `join()` calls from main.
