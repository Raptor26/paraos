# Plan 26-06: Unify test_message_multithread_many_producer_many_consumers.cpp

## Objective

Update `containers/tests/test_message_multithread_many_producer_many_consumers.cpp` to use the cross-platform
`paraos::jthread::start_scheduler()` / `end_scheduler()` pattern and remove
`std::_Exit()`.

## Must-Haves

- [ ] MH-01: No `std::_Exit()` remains in the file.
- [ ] MH-02: No `#ifdef PARAOS_LIKE_FREERTOS` platform branch remains at the end of `main()`.
- [ ] MH-03: `paraos::jthread::start_scheduler()` is called after all worker threads are created.
- [ ] MH-04: A stopper thread waits for `consumer_thread_exit_cnt.load() >= consumer_total_thread_numb.load()` and calls `paraos::jthread::end_scheduler()`.
- [ ] MH-05: Main waits on a condition variable signaled by the stopper before the worker scope ends.
- [ ] MH-06: Existing `paraos::sleep_for` calls are preserved.
