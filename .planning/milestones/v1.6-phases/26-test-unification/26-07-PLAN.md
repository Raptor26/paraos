# Plan 26-07: Build and run unified tests on PC

## Objective

Build and run all unified multithread tests on PC to confirm they compile and
pass without hangs or regressions.

## Must-Haves

- [ ] MH-01: `pc_debug_clang` builds `test_jthread_basic`.
- [ ] MH-02: `pc_debug_clang` builds all four container multithread tests.
- [ ] MH-03: `test_jthread_basic` runs and prints `OK`.
- [ ] MH-04: Each container test runs to completion on PC without timeout.
- [ ] MH-05: FreeRTOS presets still build `test_jthread_basic` and container tests.

## Tasks

### Task 1: Build PC tests

**details:**
1. Configure `pc_debug_clang`.
2. Build the following targets:
   - `test_jthread_basic`
   - `test_queue_blocking_mpsc`
   - `test_queue_blocking_spmc`
   - `test_queue_blocking_mpmc`
   - `test_multi_ringbuff_mpmc`
   - `test_message_multithread_many_producer_many_consumers`

### Task 2: Run PC tests

**details:**
1. Run each built executable with a timeout (e.g. 20 seconds).
2. Verify exit code 0.

### Task 3: Build FreeRTOS tests

**details:**
1. Build the same targets under `freertos_debug_clang` and `freertos_debug_gcc`.
2. Runtime execution on macOS POSIX simulator is not required.

### Task 4: Capture verification log

**details:**
1. Save output to `.planning/phases/26-test-unification/26-07-verification.log`.

## Verification

- All PC tests pass.
- FreeRTOS tests compile.

## Risks

- Container tests may have timing-dependent behavior; use timeout to detect hangs.
- If a test hangs, the stopper condition may be wrong or the test may need a longer timeout.
