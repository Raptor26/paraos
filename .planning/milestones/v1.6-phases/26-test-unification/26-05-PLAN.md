# Plan 26-05: Unify test_multi_ringbuff_mpmc.cpp

## Objective

Update `containers/tests/test_multi_ringbuff_mpmc.cpp` to use the cross-platform
`paraos::jthread::start_scheduler()` / `end_scheduler()` pattern and remove
`std::_Exit()`.

## Must-Haves

- [ ] MH-01: No `std::_Exit()` remains in the file.
- [ ] MH-02: No `#ifdef PARAOS_LIKE_FREERTOS` platform branch remains at the end of `main()`.
- [ ] MH-03: `paraos::jthread::start_scheduler()` is called after all worker threads are created.
- [ ] MH-04: A stopper thread waits for `consumer_total_read_bytes.load() >= container_bytes_numb` and calls `paraos::jthread::end_scheduler()`.
- [ ] MH-05: Main waits on a condition variable signaled by the stopper before the worker scope ends.
- [ ] MH-06: Existing `paraos::sleep_for` calls are preserved.

## Tasks

### Task 1: Add scheduler shutdown helpers

**read_first:**
- `containers/tests/test_multi_ringbuff_mpmc.cpp`
- `port_tests/test_jthread_basic.cpp`

**details:**
1. Add includes `<condition_variable>` and `<mutex>` if absent.
2. Add `g_scheduler_ended`, `g_done_mtx`, `g_done_cv`, and helper functions in the anonymous namespace.

### Task 2: Add stopper thread and start_scheduler call

**details:**
1. Inside the worker scope, after creating all worker threads, create a stopper thread that polls `consumer_total_read_bytes`.
2. Call `paraos::jthread::start_scheduler();` after creating the stopper.
3. Call `WaitForSchedulerEnded();` before the scope closes.

### Task 3: Remove platform branch

**details:**
1. Replace the final `#ifdef PARAOS_LIKE_FREERTOS ... #else return 0; #endif` block with `return 0;`.
