## Phase Details

### Phase 13: PC mutex implementation

**Goal**: `paraos::mutex` реализован для Windows и Unix как тонкая обёртка над `std::mutex` с единым API.
**Depends on**: Milestone v1.2 complete
**Requirements**: MUTEX-01..09, MUTEX-11, BUILD-01
**Success Criteria**:

  1. `port_pc/paraos_mutex_std.hpp` создан и содержит `paraos::mutex` с `lock()`, `try_lock()`, `unlock()`.
  2. `paraos::mutex` не копируется и не перемещается.
  3. `port_unix/paraos_mutex_std.hpp` и `port_win/paraos_mutex_std.hpp` включают `port_pc/paraos_mutex_std.hpp`.
  4. `std::lock_guard<paraos::mutex>` и `std::unique_lock<paraos::mutex>` компилируются.
  5. Публичный API не зависит от платформенных `#ifdef` в коде пользователя.

**Plans**: 1 plan

Plans:

- [x] 13-01: Реализовать `paraos::mutex` для Windows и Unix поверх `std::mutex` (MUTEX-01..09, MUTEX-11, BUILD-01)

### Phase 14: FreeRTOS mutex implementation

**Goal**: `paraos::mutex` реализован для FreeRTOS поверх FreeRTOS mutex API.
**Depends on**: Phase 13
**Requirements**: MUTEX-10
**Success Criteria**:

  1. `port_freertos/paraos_mutex_std.hpp` создан и содержит собственную реализацию `paraos::mutex`.
  2. `lock()` использует `xSemaphoreTake(handle_, portMAX_DELAY)`.
  3. `try_lock()` использует `xSemaphoreTake(handle_, 0)`.
  4. `unlock()` использует `xSemaphoreGive(handle_)`.
  5. Конструктор создаёт мьютекс через `xSemaphoreCreateMutex()` и проверяет результат.

**Plans**: 1 plan

Plans:

- [x] 14-01: Реализовать `paraos::mutex` поверх FreeRTOS mutex API (MUTEX-10)

### Phase 15: Build, tests and static analysis

**Goal**: Сборка, тесты и статический анализ проходят для нового `mutex` API.
**Depends on**: Phase 14
**Requirements**: TEST-01..05
**Success Criteria**:

  1. `port_tests/test_mutex_basic.cpp` создан, зарегистрирован в CTest и проходит на `pc_debug_clang`, `pc_debug_gcc`, `freertos_debug_clang`, `freertos_debug_gcc`.
  2. `*_clang_tidy` пресеты собираются без новых предупреждений.
  3. Все не-tidy пресеты продолжают собираться без регрессий.

**Plans**: 1 plan

Plans:

- [x] 15-01: Добавить `test_mutex_basic.cpp`, прогнать все пресеты и tidy (TEST-01..05)
