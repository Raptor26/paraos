# Requirements: PARAOS

**Defined:** 2026-06-22
**Core Value:** Кроссплатформенная переносимость PARAOS сохраняется: код, работающий на Linux/Windows/FreeRTOS, продолжает работать, а новая macOS-разработка ведётся на равных с остальными платформами, включая статический анализ clang-tidy.

## v1 Requirements

### MUTEX — Core API

- [x] **MUTEX-01**: `paraos::mutex` предоставляет метод `lock()`, блокирующий вызывающий поток до захвата мьютекса.
- [x] **MUTEX-02**: `paraos::mutex` предоставляет метод `try_lock()`, пытающийся захватить мьютекс без блокировки, и возвращающий `bool`.
- [x] **MUTEX-03**: `paraos::mutex` предоставляет метод `unlock()`, освобождающий мьютекс.
- [x] **MUTEX-04**: `paraos::mutex` не поддерживает копирование и перемещение (как `std::mutex`).
- [x] **MUTEX-05**: `std::lock_guard<paraos::mutex>` компилируется и корректно захватывает/освобождает мьютекс.
- [x] **MUTEX-06**: `std::unique_lock<paraos::mutex>` компилируется и корректно захватывает/освобождает мьютекс.

### MUTEX — Portability

- [x] **MUTEX-07**: `port_pc/paraos_mutex_std.hpp` содержит единую реализацию `paraos::mutex` для Windows и Unix поверх `std::mutex`.
- [x] **MUTEX-08**: `port_unix/paraos_mutex_std.hpp` включает `port_pc/paraos_mutex_std.hpp`.
- [x] **MUTEX-09**: `port_win/paraos_mutex_std.hpp` включает `port_pc/paraos_mutex_std.hpp`.
- [x] **MUTEX-10**: `port_freertos/paraos_mutex_std.hpp` содержит собственную реализацию `paraos::mutex` поверх FreeRTOS mutex API.
- [x] **MUTEX-11**: Пользовательский код не должен содержать платформенных `#ifdef` для выбора между `mutex`-реализациями.

### Build & Tests

- [x] **BUILD-01**: `paraos_mutex_std.hpp` доступен для включения из всех портов.
- [x] **TEST-01**: Тест `port_tests/test_mutex_basic.cpp` компилируется и проходит на `pc_debug_clang`.
- [x] **TEST-02**: Тест `port_tests/test_mutex_basic.cpp` компилируется и проходит на `pc_debug_gcc`.
- [x] **TEST-03**: Тест `port_tests/test_mutex_basic.cpp` компилируется и проходит на `freertos_debug_clang`.
- [x] **TEST-04**: Тест `port_tests/test_mutex_basic.cpp` компилируется и проходит на `freertos_debug_gcc`.
- [x] **TEST-05**: `*_clang_tidy` пресеты продолжают собираться без новых предупреждений.

## v2 Requirements

### MUTEX — Extended API

- **MUTEX-12**: `paraos::recursive_mutex` с интерфейсом, совместимым со `std::recursive_mutex`.
- **MUTEX-13**: `paraos::timed_mutex` с `try_lock_for()` / `try_lock_until()`.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Полная замена существующего `paraos::Mutex` на `paraos::mutex` | Веха v1.3 добавляет новый API рядом со старым. |
| Миграция `extra/` и `containers/` на `paraos::mutex` | Откладывается на будущие вехи. |
| `paraos::recursive_mutex` / `paraos::timed_mutex` | Только базовый `std::mutex`-подобный интерфейс в v1.3. |
| Тестирование на физических целевых устройствах | Только host-сборки. |
| Глобальное переписывание CI/CD | Вне явной области вехи. |
