# Requirements: PARAOS

**Defined:** 2026-06-24
**Core Value:** Кроссплатформенная переносимость PARAOS сохраняется: код, работающий на Linux/Windows/FreeRTOS, продолжает работать, а новая macOS-разработка ведётся на равных с остальными платформами, включая статический анализ clang-tidy.

## v1.9 Requirements

### Legacy implementation removal

- [ ] **REM-01**: Удалены `port_unix/paraos_thread.hpp`, `port_unix/paraos_mutex.hpp` и `port_unix/paraos_semaphore.hpp` (legacy-заголовки)
- [ ] **REM-02**: Удалены `port_win/paraos_thread.hpp`, `port_win/paraos_mutex.hpp` и `port_win/paraos_semaphore.hpp` (legacy-заголовки)
- [ ] **REM-03**: Удалены `port_freertos/paraos_thread.hpp`, `port_freertos/paraos_mutex.hpp` и `port_freertos/paraos_semaphore.hpp` (legacy-заголовки)
- [ ] **REM-04**: `paraos_thread_common.hpp` очищен от legacy `paraos::Thread`-специфичных API, сохранив общие `ThreadAttr`/`ThreadPriority` для `paraos::jthread`
- [ ] **REM-05**: `paraos_mutex_raii.hpp` удалён или переработан на `std::lock_guard<paraos::mutex>` / `std::unique_lock<paraos::mutex>`

### Internal code migration

- [ ] **MIG-01**: `containers/paraos_message_buffer.hpp` и `containers/paraos_queue_blocking.hpp` используют `paraos::mutex` и `paraos::*_semaphore` вместо `paraos::Mutex` / `paraos::Semaphore*`
- [ ] **MIG-02**: `port_unix/paraos_critical.hpp` использует `paraos::mutex` вместо `paraos::Mutex` / `MutexBase`
- [ ] **MIG-03**: `port_unix/paraos_thread.hpp` и `port_win/paraos_thread.hpp` либо удалены, либо заменены forwarding-заголовками на `paraos_jthread.hpp`
- [ ] **MIG-04**: `port_unix/paraos_socket_udp.hpp` и `port_win/paraos_socket_udp.hpp` используют `paraos::jthread` / `paraos::sleep_for` вместо `paraos::Thread`

### Test/example cleanup

- [ ] **TEST-01**: Legacy-тесты `port_tests/test_thread_create_then_delete_many_threads.cpp`, `port_tests/test_mutex.cpp`, `port_tests/test_mutex_raii.cpp` и `port_tests/test_semaphore.cpp` удалены или переработаны на std-like примитивы
- [ ] **TEST-02**: Примеры `port_tests/example_thread_check_timeout.cpp`, `port_tests/example_timer.cpp`, `port_tests/example_paraos_timer.cpp`, `port_tests/example_socket_udp.cpp` и `port_tests/example_paraos_socket_udp.cpp` переработаны на `paraos::jthread` / `paraos::*_semaphore` / `paraos::sleep_for`
- [ ] **TEST-03**: `port_tests/CMakeLists.txt` обновлён: удалены ссылки на удалённые тесты/примеры, добавлены/сохранены цели для новых std-like тестов

### Build and verification

- [ ] **BUILD-01**: Все PC-пресеты (`pc_debug_clang`, `pc_debug_gcc`, `pc_debug_gcc_clang_tidy`) конфигурируются, собираются и проходят `ctest` без регрессий
- [ ] **BUILD-02**: Все FreeRTOS-пресеты (`freertos_debug_clang`, `freertos_debug_gcc`) конфигурируются и собираются без ошибок
- [ ] **BUILD-03**: `*_clang_tidy` пресеты не получают новых предупреждений от изменённого/удалённого кода
- [ ] **BUILD-04**: Количество PC-тестов `ctest` не меньше baseline (58 тестов) после удаления legacy-тестов, если они не заменяются новыми

## Out of Scope

|---------|--------|
| Изменение публичного API `extra/` (`OneShotExecutor`, `ThreadSequence`, `CooperativeScheduling`) | Публичный API должен остаться неизменным |

| Глобальный рефакторинг CI/CD или документации | Вне scope вехи, если не требуется для сборки |
