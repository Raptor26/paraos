## Cross-Phase Integration

- FreeRTOS and PC `paraos::jthread` expose the same scheduler-control API: `start_scheduler()`, `end_scheduler()`, `is_scheduler_running()`.
- PC implementation emulates FreeRTOS scheduler gating so tests can be unified.
- `end_scheduler()` on PC skips self-join, allowing a worker thread to trigger shutdown.
- Multithread tests now share a single cross-platform pattern using a stopper thread and a shutdown condition variable.

## Tech Debt / Deferred Items

- FreeRTOS runtime execution on macOS POSIX simulator remains environment-limited; verification is build-only.
- Windows runtime verification remains deferred due to lack of Windows host.
- Some pre-existing clang-tidy warnings in unrelated files remain outside milestone scope.
